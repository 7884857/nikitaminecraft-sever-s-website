# Nikita Minecraft Server Website

Official website for the **Nikita Anarchy Minecraft Server**.

- **Server IP**: `mcs.nikitaminecraft.zone`
- **Version**: 26.1.2
- **Max players**: 20

## Server Features

- 絕無規則 / No Rules — Pure anarchy adventure
- 地圖永不重置 / Map never resets
- 高自由度體驗 / High freedom (survival, building, teaming, raiding)
- 社區民主自治 / Community democratic autonomy

## Website Structure

| File | Description |
|------|-------------|
| `index.html` | 首頁 / Main page |
| `finance.html` | 財務公開與支持 / Finance transparency & support |
| `links.html` | 友情連結 / Friend links |

## How to Deploy

This is a pure static website. You can deploy it to:

- GitHub Pages
- Cloudflare Pages
- Vercel / Netlify
- Any static hosting

Just point the hosting root to this repository.
