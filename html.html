💀 關於 Nikita Server

這是一個完全沒有規則、沒有地圖重置、沒有管理員介入的純粹 Minecraft 伺服器。

在這裡，實力代表一切。不論你是想成為孤傲的生存專家、建造隱密基地、還是成為洗劫一切的掠奪者，這裡都能滿足你對自由的渴望。地圖的命運完全由玩家掌握。

📋 伺服器詳細說明

  • 自由與團隊： 伺服器基本上沒有限制，允許玩家自由組建團體。
  • 輔助與外掛規範： 可以開啟輔助功能。但請注意，嚴禁使用惡性 BUG 和非法外掛（例如：刷物品、秒殺、鎖血等），違者一律予以封鎖處分。
  • 民主投票機制： 伺服器可以透過投票來改變規則。
  • 管理員選拔： 管理員由社區玩家投票選出。名額基準為每 50 人即享有 1 個管理員名額，上限為 5 位。同時，管理員亦可經由投票彈劾革職。
  • 人數上限調整： 目前基本人數上限為 20 人。若伺服器註冊人數超過 25 人，將會視伺服器性能表現逐步調高人數上限。
  • 定期維護時間： 每個星期六上午 9:00 可能會進行一次不超過 20 分鐘的例行維護。若有重大更新，將提早於伺服器內發布公告。
  • 語音語音模組： 伺服器已加入 Simple Voice Chat 近距離語音插件。
⚙️ 本伺服器加入了開源伺服器管理軟體 opanel，在此感謝 opanel 全體專案組的辛勤付出。

👁️ 舉報機制： 如在遊戲內發現任何可疑人員，請積極向管理員檢舉。

🔌 進入伺服器

1. 啟動你的 Minecraft，並確認版本為 26.1.2。

2. 進入多人遊戲，點擊「直接連線」或「新增伺服器」。

3. 輸入位置：www.nikitaminecraft.zone

4. 擠進 20 人的生存槽位，開啟你的無政府冒險。
